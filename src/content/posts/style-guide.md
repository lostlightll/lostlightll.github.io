## 二级标题

正文用系统字体，标题用得意黑。段落之间留足呼吸感，行高接近 2，适合读长文。[链接](https://astro.build)会带一条红色下划线。

### 三级标题

- 无序列表第一项
- 第二项，列表符号是强调色
- 第三项

1. 有序列表
2. 同样适用

> 引用块会变成一个对话气泡。
> 适合放别人说过的话，或者自己的吐槽。

## 代码

行内代码像 `pnpm dev` 这样。代码块用 Shiki 高亮，深色模式下会自动切换配色：

```ts
export async function getChapters() {
    const posts = await getCollection('posts');
    return posts.map((post, i) => ({ post, no: i + 1 }));
}
```
